# postapocapitalism

We create futures. Live at [postapocapitalism.org](https://postapocapitalism.org).

- `index.html`: the home page (static, served by GitHub Pages from `main`).
- `sc3ne/`, `r3mesher/`, `cad3t/`: one page per product, styled by `product.css`.
- `sitemap.xml`, `robots.txt`, `og/` (social-card images, made by `dev/og.js`): for search engines and shared links.
- `LORE.md`: canon, design language and decisions.
- `CLAUDE.md`: handover notes for anyone (human or Claude) working on the site.
- `dev/preview.js`: screenshot harness with mocked APIs.
