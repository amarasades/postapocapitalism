Sc3ne

Fashion PLM // 3D visual merchandising

Track a garment from first sketch to production run, without a six-figure enterprise contract.

Sc3ne is a desktop app for fashion teams. Garments come straight out of CLO3D into one product library, with their SKUs, colourways, fabrics and approval status. Then you build the store in 3D and dress it with the real garments, before a single sample is cut for the floor.

Also written SC3NE. Part of the postapocapitalism software family, with R3mesher and Cad3t.

What it does

06 functions
01 // Export

Straight out of CLO3D

A script you run inside CLO packs the garment, every colourway and its baked maps (colour, normal, roughness, metal, opacity, displacement) into one .sc3g package. Static, dynamic, hanging and folded simulations of the same style become one garment.

02 // Library

A product library that remembers

Name, SKU, season, category, fabrics and colourways, searchable and filtered by status. Re-import a style and it becomes v2, v3, with your edits kept and the previous version one click away. An approved product drops back to review when it changes.

03 // Build

Draw the store

Rooms, straight and curved walls, floors divided with a pen, typed lengths, snapping. Work in a true 2D plan or in 3D. Paint walls and floors, keep wall types, import your own 3D models (glTF, OBJ, FBX).

04 // Dress

Put the clothes where they go

Rails, mannequins, tables, shelving, plinths, counters and spotlights. Drop a garment on a rail and it hangs in its hanging pose, on a table it lies folded, on a mannequin it's worn in the pose you set.

05 // Fixtures

Furniture from Cad3t

Shop fixtures are designed in Cad3t and arrive as templates: change a rail's length or a shelf's depth in the store and it rebuilds to size, ready to be made.

06 // Render

Pictures you can send

A fast real-time view for building, and a Render window using Cycles, Blender's path tracer, shipped inside the app. NVIDIA card or processor, HDRI skies and a sun you can move.

How it works

Sketch → spec → sample → floor
  1. Export from CLO3DRun the Sc3ne exporter from CLO's Python menu. Pose names are checked, so a typo never turns into a second garment.
  2. Import into the libraryDrag the .sc3g onto the window. The garment shows in 3D with every colourway and map; Windows Explorer shows it as a thumbnail too.
  3. Review and approveEdit names, SKUs and fabrics, switch colourways, look at each map on its own, and move it from review to approved.
  4. Build and dress the storeDraw the space, place fixtures, hang and fold the garments. The layout saves itself.
  5. Render and shareSave the view as it is, or render a final picture with Cycles.

Questions

Is Sc3ne a CLO3D plugin?

Partly. The exporter runs inside CLO3D; everything else is a separate Windows app. You can also pack plain OBJ files without CLO.

What does PLM mean here?

Product lifecycle management: keeping every style, its colourways, fabrics, versions and approval status in one place from first sketch to production, instead of in folders and spreadsheets.

Can I try it?

Not yet. Sc3ne is in beta and not publicly downloadable.

How do you spell it?

Sc3ne, with a 3 for the e. SC3NE in capitals is the same app.
